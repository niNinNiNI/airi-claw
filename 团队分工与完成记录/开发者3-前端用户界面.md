# 开发者 3 — 前端用户界面（SolidJS Web 管理面板）

## 概述

开发者 3 负责 ESP-Claw Edge Agent 的**前端用户界面层**，基于 SolidJS 框架构建了一套完整的 Web 管理面板。用户可以通浏览器访问设备 IP，获得图形化的设备管理和配置体验。该前端实现了设备配置、状态监控、即时聊天、文件管理、能力配置等全部管理功能。

---

## 完成的核心模块

### 1. 项目基础设施 (frontend_source/)

- **工程搭建**：使用 Vite + TypeScript + SolidJS 构建
- **包管理**：pnpm workspace 管理依赖
- **TypeScript 配置**：严格模式类型检查
- **构建集成**：Vite 构建 → gzip 压缩 → 内嵌到固件

### 2. 应用入口与路由 (src/App.tsx + src/index.tsx)

- **启动引导**：`bootstrap()` 函数并行获取设备状态、能力列表、Lua 模块列表
- **Hash 路由**：使用 `hash-routing` 库实现 10 个页面的路由切换
- **懒加载**：`lazy()` 分割所有页面，首屏仅加载当前页面
- **错误处理**：启动失败时显示 Banner 错误提示
- **重启流程**：发起重启请求 → 轮询等待设备恢复（每 2 秒）→ 自动刷新

### 3. 主布局框架 (src/components/layout/)

- **Layout.tsx** — 三栏式布局：
  - 侧边栏：Desktop 固定显示 / Mobile 抽屉菜单
  - 顶栏：Logo + 在线状态指示器 + 语言切换
  - 主内容区：`max-w-5xl` 居中，响应式 padding
- **Sidebar.tsx** — 可折叠导航侧边栏，含 10 个导航节点，组织结构如下：

  ```
  Status（状态）
  ├── System Settings（系统设置，可折叠组）
  │   ├── Basic（基础设置：WiFi/AP/时区）
  │   ├── LLM（大语言模型）
  │   ├── IM（即时通讯平台）
  │   └── Search（搜索引擎）
  Memory（记忆/知识库）
  Web IM（即时聊天）
  Capabilities（能力）
  Skills（Lua 模块/Skills）
  Files（文件管理）
  ```

- **StatusBar.tsx** — 顶部状态栏：Logo + 在线状态（脉冲动画指示灯）+ 语言切换按钮
- **TabShell.tsx** — 页面容器壳，提供统一的内边距和标题
- **LanguageSwitcher.tsx** — 语言切换下拉组件

### 4. 页面模块 (src/pages/)

开发者 3 实现了 10 个功能页面：

#### StatusPage.tsx — 状态页
- 网络状态卡片：WiFi 连接状态、IP 地址、WiFi 模式、AP SSID、AP IP
- 存储状态：FATFS 存储路径
- 刷新和重启按钮

#### BasicPage.tsx — 基础设置页
- WiFi STA 配置（SSID/密码）
- AP 配置（名称/密码/行为模式）
- 时区设置（POSIX TZ 格式，中英文提示）
- 脏检测（`configTab.ts`）：保存/丢弃提示

#### LlmPage.tsx — LLM 配置页
- 6 个 LLM 提供商配置表单：
  - OpenAI（API Key + Base URL）
  - Bailian（阿里百炼）
  - DeepSeek
  - Anthropic
  - OpenAI Compatible（自定义兼容）
  - Anthropic Compatible
- 动态显示/隐藏配置表单

#### ImPage.tsx — IM 平台配置页
- 4 个 IM 平台管理（微信、飞书、QQ、Telegram）
- 微信扫码登录集成：二维码生成 + 轮询扫码状态
- 平台增删操作

#### SearchPage.tsx — 搜索引擎配置页
- Tavily 搜索 API Key 配置

#### MemoryPage.tsx — 记忆/知识库管理页
- 记忆文件的浏览与管理

#### WebImPage.tsx — 即时聊天页（核心亮点）
- **WebSocket 客户端**：与设备 WebSocket 服务端实时通信
- 自动生成唯一 Chat ID（localStorage 持久化）
- WebSocket 心跳保活（15 秒间隔）
- 断线自动重连（2 秒延迟）
- 文件附件上传（图片 → `/inbox/webim/`）
- 消息气泡布局（用户右对齐，AI 左对齐）
- 支持 Ctrl+Enter 快捷发送
- 在线状态指示灯

#### CapabilitiesPage.tsx — 能力配置页
- 设备对外提供的能力列表管理

#### SkillsPage.tsx — Lua 脚本/Skills 配置页
- Lua 模块的上传和管理

#### FilesPage.tsx — 文件管理页
- FATFS 文件系统的远程浏览、上传、下载、删除

#### SetupWizardPage.tsx — 首次设置向导
- 多步引导（Step 0-3）：
  - Step 0: LLM 配置（6 个提供商预设，一键填充默认值）
  - Step 1: IM 平台配置（微信支持二维码扫码）
  - Step 2: 搜索引擎配置（Tavily API Key）
  - Step 3: 完成并重启设备

## 技术难点与解决方案

| 难点 | 解决方案 |
|------|---------|
| 嵌入式设备性能有限 | 选择轻量级 SolidJS（无虚拟 DOM）+ TypeScript 严格模式 |
| 构建产物大小 | Vite 构建 → gzip 压缩到 ~50KB |
| 即时聊天实时性 | WebSocket + 心跳 + 断线重连 |
| 未保存数据保护 | 脏检测系统 + Hash 路由切换拦截 |
| 国际化全覆盖 | 自建轻量 i18n 引擎，无第三方依赖 |
| 响应式布局 | Desktop/Mobile 两套侧边栏模式 |
