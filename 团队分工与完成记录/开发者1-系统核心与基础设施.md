# 开发者 1 — 系统核心与基础设施

## 概述

开发者 1 负责 AIRI Edge Agent 项目的**系统底层与基础设施层**，包括硬件初始化、存储系统、Wi-Fi 通信、板级管理以及应用配置管理。这些模块是整个设备的基础骨架，确保上层应用能够正常运行。

---

## 完成的核心模块

### 1. 系统主入口与初始化 (main/main.c)

这是整个设备的入口点，负责系统启动全流程编排：

- **NVS (非易失性存储) 初始化**：`init_nvs()` — 初始化 NVS Flash 分区，处理擦除和版本升级场景
- **FATFS 文件系统挂载**：`init_fatfs()` — 将 SPI Flash 中的 `storage` 分区挂载为 FATFS 文件系统，支持写磨损均衡
- **时区配置**：`init_timezone()` — 从配置中读取 POSIX 时区字符串并设置系统时区，默认 CST-8
- **内存监控**：`memory_monitor_task()` — 周期性打印内部 RAM、最小空闲内存和 PSRAM 使用情况，辅助调试
- **应用生命周期管理**：`app_allocate_runtime_state()` / `app_free_runtime_state()` — 运行时状态的动态分配与释放
- **存储路径规划**：`app_claw_init_storage_paths()` — 定义所有子系统在 FATFS 上的目录结构（sessions、memory、skills、scripts、router_rules、scheduler、inbox）
- **Wi-Fi 状态回调**：`on_wifi_state_changed()` — 监听 Wi-Fi 连接状态变化并同步到 UI

### 2. 应用配置管理 (components/app_config/)

- **配置加载与保存**：`app_config_load()` / `app_config_save()` — 从 NVS/FATFS 读取和持久化设备配置
- **配置校验**：`app_config_validate_wifi()` — 验证 Wi-Fi 配置的合法性
- **配置转换**：`app_config_to_claw()` — 将通用配置转换为 app_claw 模块可识别的格式
- **Kconfig 集成**：通过 CMakeLists.txt 实现配置模块的编译控制

### 3. Wi-Fi 管理 (components/cmd_wifi/)

- **Wi-Fi 命令行接口**：`register_wifi_command()` — 注册 ESP-IDF 控制台 Wi-Fi 调试命令
- **Wi-Fi 状态查询**：通过 `wifi_manager` 库获取 STA 连接状态、AP 状态、IP 地址等信息
- **Captive DNS (强制门户)**：在 AP 模式下启动 Captive DNS，使连接设备自动弹出配置页面

### 4. 板级管理 (components/gen_bmgr_codes/ 及 boards/)

- **ESP Board Manager 集成**：使用 `esp_board_manager_init()` 初始化板级硬件抽象层
- **多板适配**：支持 15+ 种开发板配置：
  - Espressif: esp_box_3、esp32_p4_eye、esp32_p4_function_ev、esp32_p4_wifi6_touch_lcd_4_3、esp32_S3_DevKitC_1 等
  - LilyGO: lilygo_t_display_s3
  - M5Stack: m5stack_cores3、m5stack_sticks3
  - 其他: dfrobot_k10、waveshare_esp32_p4_nano、movecall 系列等
- **板级默认配置**：为每种开发板提供 sdkconfig.defaults.board 等预置参数

### 5. 系统重启管理

- **`main_restart_task()` / `main_restart_device()`** — 提供延迟 500ms 后软重启设备的能力

## 技术难点与解决方案

| 难点 | 解决方案 |
|------|---------|
| 多板兼容性 | 通过 ESP Board Manager 抽象硬件差异，板级配置独立管理 |
| FATFS 磨损均衡 | 使用 wear_levelling 库减少 Flash 擦写磨损 |
| NVS 版本兼容 | 检测版本变更后自动擦除重建 |
| 配置验证 | 保存前校验 Wi-Fi 配置有效性 |
